# PromoAngol Design System — derived from the existing Stitch source

The existing UI bundle is the visual source of truth. Do not introduce a new visual language unless a product requirement forces it.

## Typography

- Primary UI: Jost
- Editorial headings: Playfair Display
- Decorative/script moments: Great Vibes
- Body copy: light-weight, compact, high line-height
- Navigation: small uppercase/letter-spaced labels

## Palette

- Brand gold: `#cba557`
- Promo red: `#e53935`
- Deep neutral: `#1c1c1c`
- Text gray: `#767676`
- Surface gray: `#f8f8f8`
- Terracotta: `#a66258`
- Teal: `#357169`
- Navy: `#1a2b49`

## Layout language

- Editorial rather than dashboard-heavy.
- Generous white space.
- Large image/colour fields with restrained copy.
- Thin borders and light shadows.
- Large serif headings paired with small sans-serif labels.
- Full-width hero/callout sections where appropriate.
- Compact product/promotion cards rather than dense tables on customer-facing surfaces.

## Mobile rule

Do not simply stack every desktop card vertically. On narrow screens:

- use horizontal scrolling rails for promotions
- keep cards compact enough to preview multiple items where practical
- use horizontal navigation and bottom actions where appropriate
- retain touch targets of at least a practical mobile size
- preserve the editorial hierarchy instead of shrinking every element

## Application surfaces

The public/member experience should inherit the Stitch aesthetic directly.

The Master Admin is more operational, but should still use the same typography, spacing, colour system and restrained card language. Financial tables can be dense where necessary, but the visual hierarchy should remain calm and readable.

## Brand behaviour

PromoAngol should feel like a premium membership ecosystem, not a generic coupon marketplace. Avoid excessive badges, gradients, oversized dashboard widgets, neon status colours or stock-admin visual patterns.
