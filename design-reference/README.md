# Design reference

These files are preserved from the exact supplied Stitch bundle and should be treated as the visual source of truth.

- `agota-source.html` — original supplied HTML source
- `screen.png` — original supplied reference image

The production PromoAngol interface adapts this reference rather than replacing it with a generic SaaS dashboard: the typography, restrained palette, editorial spacing, hero composition, compact feature blocks and horizontal mobile rails are intentionally retained.
